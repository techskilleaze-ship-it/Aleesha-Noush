# Aleesha Noush — Portfolio

Static portfolio site. No build step.

## Publish on GitHub Pages
1. Create a new repository and upload everything in this folder (`index.html`, `assets/`, `README.md`) to the root.
2. Go to **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
3. The site will be live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

Keep the `assets/` folder next to `index.html` — the certificates and CV PDF load from it.
